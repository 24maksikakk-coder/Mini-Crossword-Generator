# 🧩 Mini Crossword Generator — создавай кроссворды за секунду

> «Маленькие слова — большое удовольствие»

**Mini Crossword Generator** — это набор консольных утилит для генерации простых кроссвордов (5×5 или 7×7).  
Программа создаёт сетку с пересекающимися словами, заполняет пустые клетки случайными буквами и выводит результат в виде красивой таблицы с нумерацией.

## 🚀 Особенности
- 🎲 Генерация кроссвордов размером 5×5 или 7×7.
- 📝 Поддержка пользовательского словаря (до 5-10 слов).
- 🔄 Автоматическое размещение слов по горизонтали и вертикали.
- 🎯 Нумерация слов для удобства разгадывания.
- 🖥️ Вывод в терминал с цветной подсветкой.
- 💾 Экспорт в HTML и JSON.
- 🎨 Возможность показать решение (опционально).
- 🔢 Поддержка seed для воспроизводимости.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python crossword_generator.py`         |
| Go         | стандартная библиотека               | `go run crossword_generator.go`         |
| JavaScript | Node.js, никаких                     | `node crossword_generator.js`           |
| Java       | стандартная библиотека               | `javac crossword_generator.java && java crossword_generator` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand` (для перемешивания)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby crossword_generator.rb`           |
| PHP        | стандартная библиотека               | `php crossword_generator.php`           |
